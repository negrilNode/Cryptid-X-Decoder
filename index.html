ABOUT THIS PROJECT

Cryptid X Decoder v2.0 — Advanced decryption tool for Encrypt X protected Lua scripts.

Features:

  • Single & batch decryption
  • 100% client-side processing
  • Dark/light theme toggle
  • Advanced settings panel
  • Data export/import
  • Desktop notifications
  • Full history tracking
  • Responsive design

How It Works:

  1. Extracts Script ID from URL or direct input
  2. Fetches encrypted data from GitHub
  3. Base32 decodes the script field
  4. XOR decrypts with the provided key
  5. Displays as readable Lua source code

Security:

✓ All processing happens in your browser
✓ No data sent to external servers
✓ History stored locally only
✓ 100% open source
